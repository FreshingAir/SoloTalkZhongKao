## 广东中考英语听说题型说明

广东中考英语听说采用人机对话形式，满分30分，共三大题：

| 大题 | 小节 | 分值 | 考查能力 |
|------|------|------|----------|
| 一、模仿朗读 | — | 6分 | 语音语调、朗读 |
| 二、信息获取 | 第一节 听选信息 | 9分（1.5×6） | 听力理解、三选一口头应答 |
| 二、信息获取 | 第二节 回答问题 | 6分（1.5×4） | 听力理解、口头回答 |
| 三、信息转述及询问 | 第一节 信息转述 | 7分 | 要点转述、语言组织 |
| 三、信息转述及询问 | 第二节 询问信息 | 2分 | 中译英提问 |

#### ①PartA的编辑（模仿朗读，6分）

中考PartA模仿朗读流程：听短文一遍，30秒准备，听到“开始录音”后70秒内朗读，听到“停止录音”立即中止。

要导入视频，点击选择按键，会打开与练习模式相同的文件选择界面，点击左上角三条杠，点击图库（注意是图库不是视频）即可选择相册中的视频进行上传。

上传视频后需要在下方提示输入原文文本的文本输入栏输入模仿朗读的文本，可以尝试借助AI上传视频后让其输出视频文本。如果你在B站等平台上看到合适的模仿朗读视频，可尝试通过网站https://snapany.com/zh/
在输入栏输入视频网址→提取视频图片→下载视频以获得视频文件。

编辑字段：朗读文本、视频/音频（带字幕）、准备时长（30秒）、朗读时长（70秒）。

#### ②PartB的编辑（信息获取，15分）

中考PartB信息获取分两节，均无三问翻译。

第一节 听选信息（1.5×6=9分）：听三段对话，每段播放两遍，每段播放前10秒阅题，每段后有两个问题，带括号提示（三选一），8秒内口头回答。

第二节 回答问题（1.5×4=6分）：听一段短文，播放两遍，15秒阅读四个问题，每问8秒内口头回答。

编辑字段：

- 听力材料（音频或电脑TTS朗读文本）
- 题目类型（听选信息 / 回答问题）
- 问题（英文）
- 选项提示（仅听选信息，三选一，如 a dog / a cat / a parrot）
- 参考答案（可多版本，如 She used to have a cat. / A cat.）
- 阅题时长（听选信息10秒 / 回答问题15秒）
- 回答时长（8秒）

若你所在市仍考三问，可保留“三问中文提示 / 英文机答 / 标准答案”逻辑，但请以本市考纲为准。

#### ③PartC的编辑（信息转述及询问，9分）

第一节 信息转述（7分）：听一段报道，播放两遍，15秒阅读思维导图，50秒准备，50秒内说一段话，包含五个要点，有固定开头（如 Welcome to Lynn's traffic radio.）。

第二节 询问信息（2分）：根据中文提示提两个问题，每问15秒准备+8秒提问，如“你每天几点去上班？”→ When do you go to work every day?

编辑字段：

- 听力材料（音频或电脑TTS朗读文本）
- 思维导图要点（5个）
- 起始句
- 多版本范文
- 答案要点（key_points，5个关键短语，英文逗号隔开，不要附带除英文逗号外的标点符号）
- 询问信息：中文提示 + 参考答案（可多版本）
- 准备时长（15秒读图 + 50秒准备）
- 转述时长（50秒）
- 提问准备15秒 / 提问8秒

听力材料可以选择上传音频，方法与视频的上传类似，当然，大部分情况是你没有音频文件，请选择电脑TTS朗读，并上传故事全文文本。答案要点部分请输入文本中的关键短语，不要附带除英文逗号外的标点符号，每个短语之间用英文逗号隔开，同样，你可以选择将全文文本上传给AI后，让其为你输出要点。

### 4、历史记录的使用

当你完成一次考试后，点击历史模式应该可以查看你的考试记录，与你考试结束后看到的一致，但该功能不稳定，很可能会丢失记录，建议在考试结束后截图保存当时的记录。

## SoloTalk电脑版使用指南

### 1、下载

如果在群文件下载SoloTalk，请打开群文件下载最新版的zip文件解压（若不会解压请看[电子扫盲课—网盘下载压缩文件及解压缩教学_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV11w4m1y7kA/)）解压后双击打开SoloTalk.exe即可打开软件

### 2、练习模式与模考模式的使用

打开软件时你会看到四个按键，编辑模式、练习模式、模考模式与历史记录。之所以先讲练习模式，是因为该功能是模拟听说考试的主要功能。要注意的是，该功能只是个载体，并没有内置像商业软件一样丰富的题库，所有题目均需要通过编辑模式制作并保存完文件后导入，因此该Q群的建立初衷也是供大家分享自己创造的题目，以壮大SoloTalk的题库系统。如果你现在想体验此功能，可以从群文件中的共创题目文件夹下载.solo测试题目进行尝试。

点击练习模式按键后会弹出文件选择窗口，根据下载地址找到下载的.solo文件双击打开即可根据流程开始考试。

练习时中途返回主页后相当于暂停，若不关闭软件再次选择相同题目文件会从退出的题目开始，中断的听力会重新播放，若在录音时中断会返回上一次听力材料重新播放（若不想再听一遍可以点击跳过）。

模考模式与练习模式基本一致，但会改为全屏模式，不可中途退出，不可进行跳过或上一步操作。

考试完成后会进行批改，批改结果与答案在历史记录查看。

### 3、编辑模式的使用

现阶段SoloTalk的题库非常匮乏，需要大家的共同创作分享到群文件。打开编辑模式后出现以下界面，最上一栏可以为你的题目命名与署名，署名并保存后不可再修改。新建可以清空所有编辑记录，打开.solo可以用于修改之前的题目，保存可以下载编辑好的题目文件到你指定的地址。

### 4、批改逻辑对应

| 题型 | 批改方式 |
|------|----------|
| Part A 模仿朗读 | 语音识别 + 文本相似度（word_f1 / containment_score） |
| Part B 听选信息 | 参考答案精确匹配（三选一） |
| Part B 回答问题 | 词级 F1 + containment_score |
| Part C 信息转述 | 多版本范文 + 5 个 key_points 覆盖 |
| Part C 询问信息 | 词级 F1 + 疑问词一致性 |

### 5、历史记录的使用

当你完成一次考试后，点击历史模式可以查看你的考试记录，双击打开题目文件的名字，可以看到批改结果与答案。可以在SoloTalk.exe文件的同级地址找到一个名为recording的文件夹，里面有考试的录音文件，可以重新听并自行与答案进行比对（虽然不推荐，但若想通过该软件备考，强烈建议进行此步骤，因为该软件的电脑机改是不够好的。）
